# CP Portal — Collaboration Portal

**Status: Planned (Phase 8)**

This application will be built after MIMS reaches its core feature set.

## What it will be

An embeddable web portal for pharma companies to add to their corporate websites.
End users (patients, customers, HCPs) will be able to:

- View the pharma company's product pipeline
- Submit medical inquiries (feeds into MIMS)
- Submit adverse event reports
- Submit product complaints
- Access document content (prescribing info, storage instructions, etc.)
- Interact with an integrated AI chatbot
- View conference details and event schedules

## Integration with MIMS

When a patient submits an inquiry through CP Portal, it will be automatically created as a case in MIMS — closing the loop between customer-facing intake and back-office processing.

## Tech Stack (planned)

Same as MIMS: HTML + CSS + JavaScript (frontend) | Node.js + Express (backend) | SQLite (database)
