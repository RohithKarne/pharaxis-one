# CP Portal Visual Design Options

## Option 1 - Guided Medical Self-Service

Purpose: improve the public CP Portal by making the first screen task-first instead of hero-first.

Key moves:
- Calmer safety alert.
- Strong global search with suggested quick filters.
- Three primary jobs in the first viewport: submit inquiry, find documents, contact MSL.
- Events, news, and safety shown as compact actionable rows.
- Better mobile potential because the layout can collapse into prioritized tasks.

## Option 2 - Operations Command Center

Purpose: improve admin screens by making operational urgency and workload obvious.

Key moves:
- Dashboard organized around unresolved alerts, open submissions, review queue, setup blockers, and content freshness.
- Long sidebar stays, but pinned sections and badges make it easier to scan.
- Client overview becomes readiness-first, not card-first.
- Tables and lists replace scattered cards where the user is doing repeated admin work.

## Option 3 - Unified Medical Workspace

Purpose: create one design language across public portal and admin screens.

Key moves:
- Shared component vocabulary for public and admin: status badges, alert rows, task rows, search, segmented controls, table/list rows.
- Public portal stays simple for external users.
- Admin surface stays dense for internal operators.
- Same colors, spacing, radius, and interaction patterns across both surfaces.
