# MIMS User Requirement Specification

## URS-01 Pharmacovigilance ICSR Lifecycle
MIMS shall let authorised admins create, validate, lock, submit, supersede, and audit ICSR reports from AE cases.

## URS-02 E2B(R3) XML Generation
MIMS shall generate regulator-ready E2B(R3)-structured XML from an ICSR without writing back to source AE case tables.

## URS-03 AI Case Assistant
MIMS shall provide controlled AI suggestions for classification, extraction, response drafting, summaries, similar cases, and quality checks, with audit logging.

## URS-04 Configurable Workflow Engine
MIMS shall allow tenants to define, simulate, publish, and execute configurable workflow graphs without code changes.

## URS-05 Public Integration Platform
MIMS shall expose secured versioned public APIs with OAuth2 client credentials, scopes, rate limits, webhooks, OpenAPI documentation, and API call audit logs.

## URS-06 Compliance Evidence Package
MIMS shall produce audit completeness reports, validation traceability, release evidence, compliance policy documents, data residency controls, and e-sign manifests.
