# SOC 2 Controls Mapping

Security: authentication, role guards, API client scopes, hashed secrets, rate limits, audit logs, security headers, and request IDs are implemented.
Availability: health checks, process manager restarts, scheduler separation, release validation, and backup/restore runbooks support availability evidence.
Confidentiality: PHI-safe AI fallback, encrypted provider keys, data-region routing, scoped APIs, and tenant-aware queries protect confidential data.
Processing Integrity: workflow validation, ICSR validation, traceability, migration history, and audit completeness checks reduce uncontrolled changes.
Privacy: DPPR, RTBF, consent records, data portability, and data residency controls support privacy commitments.
